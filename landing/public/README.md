# Ассеты лендинга

Сюда положить кадр-улику из Hell Grind:

- **`hero-frame.webp`** — кинематографичный AI-кадр, тёмный, со «швом»
  (намёк на стык/артефакт). Midjourney v7 (`cinematic still, dark, film grain,
  subtle AI-artifact seam`) либо реальный стоп-кадр трейлера, если есть права.
  Формат WebP, quality 80, < 2 МБ.

Пока файла нет — в hero показывается CSS-плейсхолдер (тёмный кинематографичный
градиент со «швом»). Как только положишь `hero-frame.webp`, он подхватится
автоматически (тег `<img>` в `index.html` ссылается на `public/hero-frame.webp`).
