## 0. Что это

Одностраничный лендинг для платного онлайн-воркшопа (3 часа, живой эфир) о том, как ставить Claude слоем режиссуры/оркестрации поверх хаотичной AI-генерации видео. Крючок — разбор нашумевшего AI-фильма Hell Grind и разоблачение его маркетинга («фильм за 2 недели»). Цена €50–60, аудитория русскоязычная (CIS/Молдова), эфир из Кишинёва.

Единственная задача сайта: довести посетителя до кнопки «Занять место». Всё остальное — шум.

### Нарративный якорь (КРИТИЧНО — не нарушать)

Аргумент строится на **Факте А: их собственный публично доступный стек выдаёт механику.** Не на «создатели Hell Grind признались». Higgsfield CLI ставится как обычный npm-пакет; в паре с Claude Code это конвейер-оркестратор поверх чужих генераторов (Seedance, Kling). Любой может это проверить — поэтому страница неуязвима к фактчеку. Крючок «тебе соврали» критикует публичную маркетинговую подачу («за 2 недели»), а доказательство «магии нет» опирается на публичные инструменты, а не на инсайд.

## 1. Бриф (фундамент — не править при кодинге)

1. **Чувство:** пойман с поличным. Тебе показали фокус изнутри, и развидеть уже нельзя. Дискомфорт прозрения, не восторг от «AI».
2. **Аудитория:** контент-мейкер/маркетолог, который уже гонял Midjourney и Kling, склеил пару роликов — и упёрся в потолок «нагенерил → склеил → получилось средне». **Не для:** тех, кто ищет «топ-10 промптов» и кнопку «сделай красиво».
3. **Hero-объект:** один кадр-улика из Hell Grind с перечёркнутой маркетинговой подписью («2 НЕДЕЛИ»). Не логотип Claude, не абстрактный AI-визуал.
4. **Работа (один глагол):** РАЗОБЛАЧИТЬ. Не «научить», не «вдохновить».
5. **Режем:** карусель отзывов, блок «о спикере» с парадным фото, поэпунктную программу-простыню, FAQ-аккордеон, плашки «о нас писали».
6. **Трёхсекундная память:** перечёркнутые «2 НЕДЕЛИ», слово РАЗОБЛАЧЕНИЕ во весь экран, ощущение «меня сейчас разыграли — и я хочу знать как».

**Три логики:**

- **Цвет:** почти-чёрный фон затапливает весь экран. Ровно ОДИН кислотный акцент (цвет редакторского маркера) — появляется только на разоблачении и на CTA. Больше нигде цвета нет.
- **Тайпо:** гигантский condensed-гротеск для ударных слов, обрезается краями экрана. Крошечный моноширинный для фактов и цифр. Между ними — ничего.
- **Пространство:** центр сакрален — там улика (кадр или число). Копия прижата к краям. Всё орбитой вокруг центральной улики. Края — утилитарны.

## 2. Design tokens (CSS custom properties — отдай как есть)

```css
:root {
  /* COLOR — почти-чёрный + один кислотный акцент */
  --bg:            #0A0A0B;   /* фон затапливает всё */
  --bg-elev:       #121214;   /* чуть приподнятые блоки */
  --ink:           #EDEDE8;   /* основной текст, тёплый офф-уайт */
  --ink-dim:       #6B6B6E;   /* вторичный/моно-факты */
  --accent:        #D6FB3D;   /* кислотный маркер — ТОЛЬКО разоблачение + CTA */
  --accent-ink:    #0A0A0B;   /* текст на акценте */
  --strike:        #FF3B2F;   /* перечёркивание маркетинговой лжи */

  /* TYPE */
  --font-display:  "Anton", "Oswald", sans-serif;        /* condensed, чёрный вес, режется краями */
  --font-mono:     "JetBrains Mono", ui-monospace, monospace; /* факты, цифры, лейблы */
  /* НЕТ третьего шрифта. НЕТ Inter/Roboto/Arial. */

  --fs-hero:       clamp(3.5rem, 14vw, 13rem);  /* ударные слова, кропаются */
  --fs-section:    clamp(2.2rem, 7vw, 6rem);
  --fs-body:       clamp(1rem, 1.4vw, 1.25rem);
  --fs-mono:       0.8rem;                       /* моно-лейблы маленькие */
  --tracking-mono: 0.18em;

  /* SPACE — центр сакрален, края утилитарны */
  --edge:          clamp(1.25rem, 4vw, 4rem);    /* отступ копии от краёв */
  --section-gap:   clamp(6rem, 16vh, 14rem);     /* воздух между секциями = драма */
  --maxw:          1400px;
}
```

Шрифты грузить через Google Fonts (Anton + JetBrains Mono; Oswald как fallback condensed). Preload display-шрифт в `<head>`.

> **Mobile-first.** ~90% аудитории — соцсети, то есть телефон. База CSS = телефон (одна колонка, кадр сверху → заголовок под ним). Десктопная композиция (наложение заголовка на кадр, наклон, сетки) навешивается поверх через `@media (min-width: …)`. Не наоборот.

## 3. Секции (сверху вниз — ровно эти, в этом порядке)

Порядок: **S1 hero · S2 посчитай сам · S3 их же стек · S4 поворот · S5 что остаётся · S6 формат+цена · S7 footer.**
Каждая секция: **цель → контент-слоты → layout → анимация → мобайл**.

### S1 — HERO («улика»)

- **Цель:** за 3 секунды поймать на крючок «тебя разыграли».
- **Контент:** кадр-улика из Hell Grind по центру (см. asset `hero-frame`). Поверх/рядом — маркетинговая подпись «СНЯТО ЗА 2 НЕДЕЛИ» с красным перечёркиванием (`--strike`). Заголовок (condensed, режется краями): **«ТЕБЕ СОВРАЛИ»**. Подзаголовок одной строкой моно: `онлайн-разбор AI-фильма Hell Grind · 3 часа · живой эфир`. CTA-кнопка «ЗАНЯТЬ МЕСТО».
- **Layout:** кадр dead-center, oversized, слегка наклонён. Заголовок заходит за края экрана. Подпись-моно в верхнем краю, CTA в нижнем. Центр — улика, края — текст.
- **Анимация (page-load, оркестрованная):** кадр въезжает с лёгким spring + параллакс на курсор (subtle, ≤8px). Заголовок — staggered reveal по словам (60ms). Перечёркивание «2 НЕДЕЛИ» рисуется отдельно, с задержкой ~700ms после заголовка — это момент «удара». CTA пульсирует один раз после того, как страйк дорисовался.
- **Мобайл:** кадр сверху, заголовок под ним, всё в одну колонку. Параллакс отключить. Страйк-анимацию сохранить — это ядро.

### S2 — ПОСЧИТАЙ САМ (цифры)

- **Цель:** показать механику обмана через факты, которые легко пересчитать.
- **Хедлайн:** **«ПОСЧИТАЙ САМ»** (condensed).
- **Контент:** 3 моно-факта крупными цифрами, каждый с короткой расшифровкой:
  - `960` — «не минуты — клипы по 15 секунд».
  - `61 487` — «сырых генераций до отбора. ≈64 попытки на один кадр в монтаже».
  - `15` — «человек в команде. И человеческий сценарий. Вот это и есть „за скобками” слова „за две недели”».
- **Layout:** три блока, цифры гигантским моно, выровнены по левому краю (утилитарный край). Акцент `--accent` только на одной ключевой цифре (`61 487`). Много воздуха между.
- **Анимация:** цифры считаются вверх (count-up) при scroll-into-view, 120ms stagger между блоками. Респектить prefers-reduced-motion (показать финальное значение сразу).
- **Мобайл:** одна колонка, цифры остаются крупными.

### S3 — ИХ ЖЕ СТЕК (мост-доказательство) — НОВАЯ

- **Цель:** перевести разоблачение из «мы посчитали» в «проверь сам» — публичный стек доказывает, что магии нет. Это мост между цифрами и тезисом.
- **Хедлайн:** **«МАГИИ НЕТ. ЕСТЬ ПАЙПЛАЙН.»** (condensed, режется краями).
- **Контент (моно-абзац):** «Их же экосистема выдаёт механику. Higgsfield CLI ставится как обычный npm-пакет. В паре с Claude Code он становится конвейером: Claude разворачивает промпты под Seedance и Kling, гоняет батчи, ведёт отбор. Не „фильм-машина” — оркестратор поверх чужих генераторов. Они продают авторство. Под капотом — инженерный слой. Тот самый, которым можешь управлять ты.»
- **Layout:** хедлайн крупно. Абзац — моно, прижат к левому/нижнему краю, как «документация/улика». Названия инструментов (`Higgsfield CLI`, `Claude Code`, `Seedance`, `Kling`) подсвечены ярче (`--ink`), остальной текст спокойнее. БЕЗ акцентного цвета — он зарезервирован (§6). Без терминальных команд, которые нельзя проверить, — только проверяемые факты.
- **Анимация:** хедлайн — построчный mask-reveal; абзац — fade-in при scroll-into-view.
- **Мобайл:** одна колонка, хедлайн через clamp остаётся ударным.

### S4 — ПОВОРОТ (тезис)

- **Цель:** перевести разоблачение в инсайт — ради чего вообще пришли.
- **Контент:** одна большая фраза condensed-шрифтом: **«КАРТИНКУ AI ЗАКРЫЛ. РЕЖИССУРУ — НЕТ.»** Под ней моно-абзац: «Генерить научились все. Управлять генерацией — почти никто. Ценность ушла от „кто умеет нажать” к „кто держит структуру”. Этому и учу.»
- **Layout:** фраза по центру, во весь экран, режется краями. Абзац мелким моно прижат к нижнему краю. Слово «РЕЖИССУРУ» — единственное в `--accent`.
- **Анимация:** фраза появляется построчно при скролле (line-by-line mask reveal). Без излишеств.
- **Мобайл:** размер фразы вниз через clamp, остаётся ударной.

### S5 — ВОТ ЧТО ОСТАЁТСЯ (4 блока, не «программа»)

- **Цель:** ценность как актив, не как расписание. Мы режем поэпунктную простыню — вместо неё 4 жёстких результата.
- **Хедлайн:** **«ВОТ ЧТО ОСТАЁТСЯ»** (condensed).
- **Контент:** 4 пункта, каждый = глагол + что получишь:
  1. **Структуру** — как Claude держит сценарий, character bible и консистентность вместо хаоса «нагенерил-склеил».
  2. **Промпты под модель** — почему промпт под Midjourney ≠ промпт под видео-модель, и как Claude разворачивает короткий запрос в рабочий.
  3. **Отбор** — как из сотен генераций оставить те, что монтируются в историю.
  4. **Методички** — забираешь шаблоны и промпт-структуры с собой. Это актив, а не запись лекции.
- **Layout:** 2×2 сетка на десктопе, утилитарная — тонкие линии-разделители (`--ink-dim`), моно-нумерация 01–04, condensed-заголовок пункта, моно-описание. Никаких иконок, никаких карточек с тенями.
- **Анимация:** fade + lift при scroll-into-view, 120ms stagger.
- **Мобайл:** одна колонка, разделители-линии остаются.

### S6 — ОДИН ВЕЧЕР, БЕЗ ВОДЫ (формат + цена, CTA-блок)

- **Цель:** снять трение и закрыть.
- **Хедлайн:** **«ОДИН ВЕЧЕР, БЕЗ ВОДЫ»** (condensed).
- **Контент:** моно-список фактов: `3 часа · живой эфир · Zoom · запись остаётся · методички в чате`. Цена крупно. **Якорь честности:** подпись моно — «цена пилотного запуска» (рядом с ценой, мелко). Дата/время эфира. Большая CTA «ЗАНЯТЬ МЕСТО» в `--accent`. Под кнопкой моно: «мест ограничено — это живой разбор, не вебинар на тысячу».
- **Layout:** цена и CTA по центру (сакральный центр), факты прижаты к краю. Акцент только на кнопке (см. §6).
- **Анимация:** магнитный CTA (кнопка тянется к курсору в радиусе 40px). На мобайле — обычный tap.
- **Мобайл:** одна колонка, кнопка широкая.

### S7 — FOOTER (минимальный)

- **Цель:** закрыть страницу, не открывая новых дверей.
- **Контент:** имя/бренд, строка-подпись «Не учу нажимать кнопки — показываю, кто на самом деле держит камеру.», ссылка на Telegram-канал, год. Всё моно, мелко, `--ink-dim`. Без колонок, без «о нас», без соцсетей-простыни.
- **Layout:** одна строка/столбик по нижнему краю.

> Чего на сайте НЕТ (вырезано намеренно — не возвращать): карусель отзывов, парадное фото спикера, длинная программа по минутам, FAQ-аккордеон, плашки «о нас писали», логотипы клиентов, поп-ап рассылки.

## 5. Тех-стек и анимации

- **Стек:** plain HTML/CSS/JS (сайт одностраничный — Next.js избыточен). Если очень хочешь компоненты — Next.js, но не усложняй.
- **Анимации:** GSAP + ScrollTrigger (как в PDF Textura, шаг 09). Hero-spring и count-up — GSAP. Магнитный CTA — vanilla JS на mousemove.
- **Обязательно:** `@media (prefers-reduced-motion: reduce)` — отключает параллакс, count-up, магнит; показывает финальные состояния сразу. Без JS контент тоже виден (прогрессивное улучшение).

## 6. Acceptance-критерии (перед деплоем — шаг 10–11 Textura)

- [ ] Lighthouse Performance 90+
- [ ] Контраст текста ≥ AA (4.5:1) — проверить офф-уайт на почти-чёрном (ок) и моно-dim (на грани, проверить)
- [ ] Display-шрифт preload в `<head>`, остальные — `font-display: swap`
- [ ] Hero-кадр: explicit width/height, lazy для всего ниже первого экрана
- [ ] Все изображения WebP, видео (если будет лупом) MP4+WebM < 2MB
- [ ] prefers-reduced-motion реально отключает движение
- [ ] Акцентный цвет встречается РОВНО в 3 местах: ключевая цифра в S2, слово «РЕЖИССУРУ» в S4, CTA в S6. Если больше — лишнее убрать. (Новая S3 «их стек» — БЕЗ акцента.)
- [ ] Мобайл: всё в одну колонку < 768px, страйк-анимация в hero сохранена

## 7. Деплой (шаг 11 Textura)

1. `git init && git add . && git commit -m "init"`
2. GitHub → новый приватный репо → push existing repository.
3. Vercel → Add New Project → выбрать репо → framework «Other» (для plain HTML) → Deploy.
4. Кастомный домен через DNS (A-record / CNAME), HTTPS автоматом.
5. Прогнать Lighthouse на проде, добить до 90+.
